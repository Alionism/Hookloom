# هوک‌لوم (Hookloom)

اپلیکیشن اندرویدی فارسی برای **تحقیق ریلز ویرال اینستاگرام** و ساخت **سناریوی کامل ریل با هوش مصنوعی**.

اپ فرم اطلاعات کسب‌وکار را با وب‌هوک به ورک‌فلوی n8n می‌فرستد، پیشرفت پردازش را زنده نشان می‌دهد و در پایان نتیجه را (سناریو، الگوهای ویرال، ریلزهای تحلیل‌شده، نظر شورای مدل‌ها) نمایش می‌دهد.

## معماری

```
اپ ──POST /webhook/hookloom/order──▶ n8n ──▶ Apify → Gemini → شورای Claude/GPT/Gemini ──▶ Google Sheets
                                       │                                                     ▲
                                       └── پایان/خطا: POST به Apps Script ──▶ ایمیل نتیجه     │
اپ ──GET (فقط با دکمه «بروزرسانی»)──▶ Apps Script (Web App) ──────────────────────────────────┘
```

- اپ هیچ پولینگ یا درخواست خودکاری ندارد؛ فقط با اقدام کاربر (ثبت سفارش، دکمه بروزرسانی) درخواست می‌زند.
- خواندن نتیجه از Apps Script انجام می‌شود و هیچ execution ای در n8n مصرف نمی‌کند. تکه‌های JSON بزرگ (`*_2`, `*_3` ...) همان‌جا به هم چسبانده می‌شوند.
- در پایان کار (یا خطا) ورک‌فلو یک‌بار Apps Script را صدا می‌زند و ایمیل نتیجه (با متن کامل سناریو) می‌رسد.
- خطاهای ورک‌فلو با Error Trigger گرفته و سفارش به‌صورت failed علامت می‌خورد.
- وب‌هوک order با هدر **`X-Call-Key`** (Header Auth) محافظت می‌شود.

## راه‌اندازی Apps Script (یک‌بار، بدون Firebase)

1. در گوگل شیت `Hookloom Data`: Extensions → Apps Script. محتوای `apps-script/Code.gs` را جایگذاری و ذخیره کنید.
2. Project settings → Script properties: `CALL_KEY` = همان مقدار `X-Call-Key`. (اختیاری: `NOTIFY_EMAIL`)
3. Deploy → New deployment → Web app → Execute as: **Me**، Who has access: **Anyone**. آدرس `/exec` را کپی کنید.
4. در n8n در دو نود `Notify Email (Done)` و `Notify Email (Failed)` مقدار `YOUR_DEPLOYMENT_ID` در URL را با آدرس بالا عوض و نودها را Enable کنید (ورک‌فلو را دوباره Publish کنید).
5. در اپ: تنظیمات → «آدرس API نتیجه» را وارد کنید.

## صفحات اپ

| صفحه | کار |
|---|---|
| سفارش جدید | فرم کسب‌وکار، مخاطب، موضوع، هدف، لحن، تنظیمات پیشرفته جست‌وجو |
| پروژه‌ها | فهرست سفارش‌ها با وضعیت و درصد پیشرفت |
| جزئیات پروژه | مراحل زنده، سناریو (شات‌لیست، پرامپت‌های AI، گویندگی، موسیقی، کپشن)، الگوها، ریلزها، شورا، متن کامل |
| تنظیمات | آدرس سرور n8n، کلید دسترسی، تست اتصال |

## راه‌اندازی

1. در n8n ورک‌فلوی **Hookloom Engine** را **Publish** کنید.
2. اپ را نصب و در «تنظیمات» آدرس سرور و مقدار `X-Call-Key` را وارد و «تست اتصال» را بزنید.
3. از «سفارش جدید» کار را شروع کنید (پردازش کامل ۱۵ تا ۴۰ دقیقه).

## ساخت APK

با هر Push روی `main` (یا اجرای دستی از تب Actions) workflow به نام **Build Android APK** اجرا می‌شود و فایل `Hookloom.apk` را:

- در **Releases** ریپو منتشر می‌کند،
- و به‌عنوان Artifact همان اجرا ذخیره می‌کند.

### ساخت محلی

نیازمند Node 20، JDK 21 و Android SDK:

```bash
npm install
npm run fonts
npx cap add android
npm run android:icons
npx cap sync android
cd android && ./gradlew assembleDebug
# خروجی: android/app/build/outputs/apk/debug/app-debug.apk
```

> APK خروجی با کلید Debug امضا می‌شود و برای نصب مستقیم مناسب است. برای انتشار در مارکت‌ها باید امضای Release اضافه شود.
